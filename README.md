# Editorial Luxe

A modern luxury editorial storefront built with TanStack Start, React, and TypeScript.

## Development

You need Node.js (or Bun) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
